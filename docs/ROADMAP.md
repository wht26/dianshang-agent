# 买家客服后续方向

当前优先服务服装鞋包的商品咨询和售后解释。

1. 用真实商品和规则替换演示资料，增加来源、更新日期、适用渠道和复核流程。
2. 建立尺码、面料、色差、洗护、开胶、破损、退换运费等专家评审问答集，测量事实准确率、必要补问、错误承诺和转人工指引质量。
3. 改善同款多SKU、同名商品、比较与切换商品的识别；增强缺失信息与冲突规则处理。
4. 有明确需求与授权后，再接入平台会话和订单只读查询；独立做身份校验，不因提供订单号就开放订单数据。

现在不承诺覆盖所有问题、实时平台规则或自动完成售后。接待建议和少量模型烟雾测试不能替代真实买家质量评测。

## v0.9 已实现与后续接入

已实现单店统一订单/库存/物流/退款台账、商家鉴权、订单访问凭证及HTTPS网关协议。后续在获得商家应用授权后实现官方接口映射、OAuth与令牌刷新、回调验签、物流服务和真实渠道联调。公网服务仍需统一管理权限、可信买家身份、审计保留策略、租户隔离和运维监控。
